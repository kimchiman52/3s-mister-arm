# RECORD-class documents, one glob per line.
#
# A RECORD is a document that describes a moment rather than the present: a
# proposal for work not yet done, or a write-up of work that has since been
# superseded. In a record, naming a file or a function that does not exist is
# the document doing its job.
#
# A REFERENCE -- everything not listed here, including every in-tree code
# comment -- claims to describe what IS. There, a name that resolves to nothing
# is a defect, because a reader who follows it finds nothing.
#
# This affects existence findings only (phantom-path, phantom-identifier,
# wrong-path), which drop from error to advisory. It does NOT affect drift or
# line-out-of-range: those cite files that exist right now at the wrong line,
# which is equally wrong and equally mechanical to fix in either class.
#
# Keep this list SHORT and justified. Every entry is a place the linter has
# been told to stop looking; that is a cost, not a convenience.

docs/plan-*.md          # proposals: they name the files they intend to create
docs/*-review.md        # reviews OF proposals, quoting their not-yet-real names
docs/fix-plan-*.md      # proposals under a different prefix
